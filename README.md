# DROPDEALER — презентация для дилеров

Интерактивная презентация (9 слайдов, версии для ПК и телефона).

- Основная ссылка: https://nkmoigg-debug.github.io/Presentation/
- Персональная ссылка: добавь `?d=Название` (например `?d=Автомир`). Название подставится в первый и последний слайды.
- Генератор ссылок: `/link.html`
- Тикер с лотами обновляется автоматически (`lots.json`, GitHub Actions раз в 30 минут).
